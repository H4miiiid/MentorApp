# MentorApp
A mentorship app for students to connect with mentors and ask questions.

## Features
- User registration and login
- Mentor and student profiles
- Mentor availability and scheduling
- Question and answer system
- Notification system
- Chat system

## Technologies Used
- Python
- Django
- PostgreSQL
- Bootstrap
- JavaScript
- jQuery
- HTML
- CSS

## Installation
1. Clone the repository:
```
git clone https://github.com/yourusername/mentorapp.git
```
2. Create a virtual environment:
```
python -m venv venv
```
3. Activate the virtual environment:
```
venv\Scripts\activate
```
4. Install the dependencies:
```
pip install -r requirements.txt
```
5. Create a PostgreSQL database and update the `DATABASES` setting in `mentorapp/settings.py` with your database credentials.
6. Run the migrations:
```
python manage.py migrate
```
7. Create a superuser:
```
python manage.py createsuperuser
```
8. Run the development server:
```
python manage.py runserver
```
9. Open your browser and go to `http://localhost:8000` to see the app.

## Usage
1. Register a new account or log in with an existing account.
2. Create a profile and update your information.
3. Browse the list of mentors and find one that you want to connect with.
4. Schedule a meeting with the mentor by selecting a date and time.
5. Ask questions and receive answers from the mentor.
6. Receive notifications for new messages and scheduled meetings.
7. Chat with the mentor in real-time using the chat system.
