# Fine-Tuning Qwen

This repository contains the code for fine-tuning the Qwen model on the MNIST dataset using the Hugging Face Transformers library. The fine-tuning process involves training the model on the MNIST dataset and evaluating its performance on the test set.

## Prerequisites

To run the code in this repository, you need to have the following installed:

- Python 3.8 or higher
- PyTorch 1.10 or higher
- Hugging Face Transformers library
- MNIST dataset

You can install the required libraries using pip:

```bash
pip install torch transformers
```

## Usage

To fine-tune the Qwen model on the MNIST dataset, follow these steps:

1. Clone this repository to your local machine:

```bash
git clone https://github.com/your-username/Fine-Tuning-Qwen.git
```

2. Navigate to the repository directory:

```bash
cd Fine-Tuning-Qwen
```

3. Run the fine-tuning script:

```bash
python fine_tune_qwen.py
```

This will start the fine-tuning process. The script will download the Qwen model, load the MNIST dataset, and train the model on the training set. The model will be evaluated on the test set after each epoch.

4. Monitor the training progress and evaluation results. The script will print the loss and accuracy for each epoch.

5. Once the training is complete, the fine-tuned model will be saved in the `output` directory.

## Fine-Tuning Script

The fine-tuning script `fine_tune_qwen.py` contains the following code:

```python
import torch
from transformers import AutoModelForSequenceClassification, AutoTokenizer, Trainer, TrainingArguments
from datasets import load_dataset

# Load the Qwen model and tokenizer
model_name = "qwen/Qwen-7B"
model = AutoModelForSequenceClassification.from_pretrained(model_name, num_labels=10)
tokenizer = AutoTokenizer.from_pretrained(model_name)

# Load the MNIST dataset
dataset = load_dataset("mnist")

# Preprocess the dataset
def preprocess_function(examples):
    inputs = tokenizer(examples["image"], return_tensors="pt")
    labels = torch.tensor(examples["label"], dtype=torch.long)
    return {"input_ids": inputs["input_ids"], "labels": labels}

dataset = dataset.map(preprocess_function, batched=True)

# Split the dataset into training and test sets
train_dataset = dataset["train"]
test_dataset = dataset["test"]

# Define the training arguments
training_args = TrainingArguments(
    output_dir="./output",
    num_train_epochs=3,
    per_device_train_batch_size=16,
    per_device_eval_batch_size=16,
    warmup_steps=500,
    weight_decay=0.01,
    logging_dir="./logs",
)

# Create the Trainer object
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    eval_dataset=test_dataset,
)

# Train the model
trainer.train()

# Evaluate the model on the test set
trainer.evaluate()
```

## Fine-Tuning Results

The fine-tuning process will produce the following results:

- The fine-tuned model will be saved in the `output` directory.

## Fine-Tuning Parameters

The fine-tuning script allows you to customize the following parameters:

- `model_name`: The name of the Qwen model to be fine-tuned. Default is "qwen/Qwen-7B".
- `num_train_epochs`: The number of training epochs. Default is 3.
- `per_device_train_batch_size`: The batch size for training. Default is 16.
- `per_device_eval_batch_size`: The batch size for evaluation. Default is 16.
- `warmup_steps`: The number of warmup steps for the learning rate scheduler. Default is 500.
- `weight_decay`: The weight decay for the optimizer. Default is 0.01.

You can modify these parameters in the script to fine-tune the model with different settings.
