# Python Bug Fixer

This repository contains a Python script that acts as a bug fixer. It takes incorrect Python code as input and attempts to correct it. The corrected code is then returned in a specific XML-like format.

## Usage

1. Clone this repository to your local machine.
2. Navigate to the repository directory.
3. Run the script using the following command:
   ```
   python bug_fixer.py
   ```
4. Follow the prompts to provide the incorrect Python code.
5. The corrected code will be displayed in the console.

## XML-like Format

The corrected code is returned in the following XML-like format:

```xml
<correct_code>
...full corrected python code...
</correct_code>
<error_type>
...one short line describing the original bug type...
</error_type>
```

## Example

Here's an example of how to use the bug fixer:

```
Incorrect code:
def add_numbers(a, b):
    return a - b

print(add_numbers(5, 3))
```

The bug fixer will identify the error in the code and correct it:

```xml
<correct_code>
def add_numbers(a, b):
    return a + b

print(add_numbers(5, 3))
</correct_code>
<error_type>
Incorrect use of subtraction instead of addition.
</error_type>
```
