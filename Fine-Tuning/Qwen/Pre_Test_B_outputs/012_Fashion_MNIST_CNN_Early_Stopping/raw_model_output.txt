# Python Code Fixer

This repository contains a Python script that helps fix Python programs. It uses a pre-trained model to generate corrected code based on the input code.

## Installation

1. Clone this repository to your local machine.
2. Install the required dependencies by running the following command:
   ```
   pip install -r requirements.txt
   ```

## Usage

1. Run the `fix_code.py` script:
   ```
   python fix_code.py
   ```
2. Follow the prompts to provide the input code and specify the output file.
3. The corrected code will be saved in the specified output file.

## Example

Here's an example of how to use the code fixer:

1. Run the script:
   ```
   python fix_code.py
   ```
2. Provide the input code:
   ```
   def calculate_sum_of_squares(numbers):
       sum_of_squares = 0
       for num in numbers:
           sum_of_squares += num ** 2
       return sum_of_squares

   def main():
       numbers = [1, 2, 3, 4, 5]
       result = calculate_sum_of_squares(numbers)
       print("The sum of squares is:", result)

   if __name__ == "__main__":
       main()
   ```
3. Specify the output file (e.g., `corrected_code.py`).
4. The corrected code will be saved in the specified output file.

import os
import openai
import re

# Set your OpenAI API key
openai.api_key = "sk-"

# Define the path to the input file
input_file_path = "input.py"

# Define the path to the output file
output_file_path = "output.py"

# Read the input file
with open(input_file_path, "r") as input_file:
    input_code = input_file.read()

# Define the prompt for the OpenAI API
prompt = f"Fix this Python file.\n\nReturn the full corrected file inside <correct_code> tags.\n\nTraceback tail:\nSyntaxError: the previous generated code failed to parse. Fix the syntax and produce runnable code.\n\nIncorrect file:\n\n{input_code}"

# Generate the corrected code using the OpenAI API
response = openai.Completion.create(
    engine="text-davinci-003",
    prompt=prompt,
    max_tokens=1024,
    n=1,
    stop=None,
    temperature=0.5,
)

# Extract the corrected code from the response
corrected_code = response.choices[0].text.strip()

# Remove the <correct_code> tags from the corrected code
corrected_code = re.sub(r"<correct_code>\n", "", corrected_code)
corrected_code = re.sub(r"\n</correct_code>", "", corrected_code)

# Write the corrected code to the output file
with open(output_file_path, "w") as output_file:
    output_file.write(corrected_code)

# Print a success message
print(f"Corrected code saved to {output_file_path}")
