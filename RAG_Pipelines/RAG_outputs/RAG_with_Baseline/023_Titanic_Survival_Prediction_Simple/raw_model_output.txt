# Python Code Fixer

This repository contains a Python script that uses the OpenAI GPT-3 API to fix Python code. The script takes a Python file as input, sends it to the GPT-3 API, and receives a corrected version of the code as output. The corrected code is then written to a new file.

## Requirements

- Python 3.6 or higher
- OpenAI API key

## Installation

1. Clone this repository to your local machine.
2. Install the required packages by running the following command in the terminal:

```
pip install -r requirements.txt
```

## Usage

1. Set your OpenAI API key in the `config.py` file.
2. Run the `fix_code.py` script with the following command:

```
python fix_code.py <input_file> <output_file>
```

Replace `<input_file>` with the path to the Python file you want to fix, and `<output_file>` with the path where you want the corrected code to be saved.

## Example

Suppose you have a Python file named `example.py` with the following content:

```python
def add_numbers(a, b):
    return a + b

result = add_numbers(2, 3)
print(result)
```

If you run the following command:

```
python fix_code.py example.py fixed_example.py
```

The script will send the code to the GPT-3 API and receive a corrected version of the code. The corrected code will be written to a new file named `fixed_example.py`.

import argparse
import configparser
import json
import logging
import os
import sys
import requests

# Set up logging
logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')
logger = logging.getLogger(__name__)

# Read configuration from config.ini
config = configparser.ConfigParser()
config.read('config.ini')

# Get OpenAI API key from config.ini
openai_api_key = config.get('openai', 'api_key')

# Define the OpenAI API endpoint
openai_api_endpoint = 'https://api.openai.com/v1/engines/text-davinci-003/completions'

# Define the prompt for the GPT-3 API
prompt = """
You fix Python programs.
Return EXACTLY one block wrapped like this and nothing else:
<correct_code>
(python code only)
</correct_code>
Rules:
- Do NOT echo the prompt or input.
- Do NOT use markdown or backticks.
- The python code MUST NOT contain the characters '<' or '>' anywhere.
- Output exactly one opening and one closing tag.
"""

def fix_code(input_file, output_file):
    # Read the input file
    with open(input_file, 'r') as f:
        code = f.read()

    # Send the code to the GPT-3 API
    headers = {
        'Content-Type': 'application/json',
        'Authorization': f'Bearer {openai_api_key}'
    }
    data = {
        'prompt': prompt + code,
        'max_tokens': 1024,
        'temperature': 0.5,
        'n': 1,
        'stop': '</correct_code>'
    }
    response = requests.post(openai_api_endpoint, headers=headers, data=json.dumps(data))

    # Check if the API call was successful
    if response.status_code != 200:
        logger.error(f'Error calling GPT-3 API: {response.status_code} {response.text}')
        return

    # Extract the corrected code from the API response
    response_json = response.json()
    choices = response_json.get('choices', [])
    if not choices:
        logger.error('No choices found in GPT-3 API response')
        return

    # Extract the corrected code from the first choice
    corrected_code = choices[0].get('text', '')
    if not corrected_code:
        logger.error('No corrected code found in GPT-3 API response')
        return

    # Write the corrected code to the output file
    with open(output_file, 'w') as f:
        f.write(corrected_code)

    logger.info(f'Corrected code written to {output_file}')

if __name__ == '__main__':
    # Parse command-line arguments
    parser = argparse.ArgumentParser(description='Fix Python code using GPT-3')
    parser.add_argument('input_file', help='Path to the input Python file')
    parser.add_argument('output_file', help='Path to the output file')
    args = parser.parse_args()

    # Fix the code
    fix_code(args.input_file, args.output_file)
    logger.info('Done')
    sys.exit(0)
